# Task1-codsoft-
Task 1 – Data Cleaning

Objective

Clean a raw sales dataset using Python and Pandas.

Tools Used

- Python
- Pandas
- Pydroid 3

Steps Performed

1. Loaded the raw CSV dataset.
2. Handled missing values in Quantity and Price.
3. Cleaned text formatting.
4. Converted Order_Date into proper date format.
5. Removed duplicate records.
6. Created the Total_Sales column.
7. Saved the cleaned data as "task1_cleaned_dataset.csv".

Input File

"task1_raw_dataset.csv"

Output File

"task1_cleaned_dataset.csv"

Result

The raw sales dataset was successfully cleaned and the cleaned dataset was generated.
